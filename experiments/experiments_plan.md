# EmailGuard XAI 검증 실험 계획

## 검증 대상

EMBER 계열 295차원 PE 피처를 사용하는 EmailGuard kNN 거리 기반
통과/의심/차단 판정에 대한 로컬 설명 모듈을 검증한다.

현재 설명 모듈은 피처를 다음 세 그룹으로 구분한다.

1. 일반 PE 정보
2. 섹션 정보
3. 데이터 디렉터리 정보

각 그룹을 정상 참조값으로 교체했을 때 악성 근접도가 얼마나
감소하는지를 계산하여 해당 그룹의 영향도로 사용한다.

## 실험 대상 판정

XAI 설명은 suspicious 판정에만 제공한다.

- safe: explanation은 null
- suspicious: explanation 객체 제공
- blocked: explanation은 null

## 검증 질문

1. XAI 모듈의 판정이 기존 탐지기와 동일한가?
2. 중요하다고 설명한 피처 그룹이 실제 모델 점수에 영향을 주는가?
3. 정상 기준값이 달라져도 설명이 유지되는가?
4. 한국어 설명이 실제 추출값과 일치하는가?
5. 요청할 때만 설명을 생성하면 처리시간이 얼마나 줄어드는가?
6. 사용자가 설명을 올바르게 이해할 수 있는가?

## 제한사항

- 기존 학습 데이터와 평가 파일의 중복 여부를 완전히 확인할 수 없다.
- 따라서 탐지 모델의 일반화 성능을 입증하는 실험으로 해석하지 않는다.
- 피처 그룹 교체 결과는 모델 입력 공간에서의 변화이며,
  실제 PE 파일을 수정했을 때의 결과를 의미하지 않는다.
