# EmailGuard XAI 최종 실험 규약

## 1. 검증 대상

EMBER 계열 295차원 PE 피처를 사용하는 EmailGuard kNN 거리 기반
통과·의심·차단 판정의 로컬 설명 모듈을 검증한다.

본 XAI는 다음 세 피처 그룹을 설명 대상으로 사용한다.

1. general: 0~9
2. sections: 10~264
3. datadirectories: 265~294

XAI 설명은 suspicious 판정 파일에만 생성한다.

- safe: explanation = null
- suspicious: explanation 객체
- blocked: explanation = null

## 2. 설명 방식

각 피처 그룹을 정상 참조값으로 교체한 뒤 악성 근접도 변화를
측정한다.

영향도는 다음과 같이 계산한다.

impact = 원본 악성 근접도 - 교체 후 악성 근접도

impact가 클수록 해당 그룹이 원본 악성 근접도를 높이는 데
더 많이 관련된 것으로 설명한다.

운영 설명에는 ben_pool StandardScaler의 mean_을 정상 기준값으로
사용한다.

## 3. 실험 1: 탐지기 일치성

목적:
기존 탐지기와 XAI 어댑터가 같은 판정과 거리값을 계산하는지
확인한다.

통과 기준:

- 판정 일치율 100%
- 분석 오류 0개
- ratio 절대 차이 0.0001 이하

이 실험은 탐지 정확도가 아니라 구현 일치성을 검증한다.

## 4. 실험 2: 설명 충실도

목적:
XAI가 제시한 그룹 순서가 역순보다 악성 근접도를 더 빠르게
낮추는지 확인한다.

측정값:

- XAI 순서 AOPC
- 역순 AOPC
- 가능한 6개 순서의 평균 AOPC
- XAI 순서의 순위

통과 기준:

- 평균 XAI AOPC가 평균 역순 AOPC보다 큼
- 파일의 75% 이상에서 XAI AOPC가 역순 AOPC보다 큼
- 분석 오류 0개

## 5. 실험 3: 정상 기준값 민감도

비교 기준:

- 모델 내부 정상 평균
- 외부 정상 파일 평균
- 외부 정상 파일 중앙값
- 외부 정상 파일 각각의 피처값

통과 기준:

- 외부 평균의 최상위 그룹 일치율 80% 이상
- 외부 중앙값의 최상위 그룹 일치율 80% 이상
- 개별 정상 파일 기준 최상위 그룹 일치율 75% 이상
- 그룹별 영향도 부호 변경률 20% 이하
- 분석 오류 0개

기준 미달 시 결과를 삭제하지 않고 기준값 민감성의 한계로
보고한다.

## 6. 실험 4: 설명 출력 자동 검사

목적:
생성된 설명의 구조가 내부 계산 결과와 일치하고,
거리 기반 점수를 확률로 잘못 표현하지 않는지 확인한다.

통과 기준:

- 자동 구조 검사 통과율 100%
- 피처 그룹 제목과 계산 결과가 일치함
- 정적 관찰 개수가 추출 결과와 일치함
- summary와 disclaimer가 존재함
- probability_word_found가 모든 파일에서 False
- 분석 오류 0개

사람이 문장별로 supported, overstated, unsupported를 입력하는
수동 내용 검토는 검토 기준의 주관성과 반복적인 입력 오류로 인해
이번 실험 범위에서 제외한다.

따라서 본 실험은 설명 문장의 사용자 이해도나 의미적 적절성을
입증하지 않는다.

## 7. 실험 5: 처리시간 및 설명 호출 절감

정책:

1. 모든 파일에서 설명 생성
2. 의심 파일에서만 설명 생성
3. 의심 파일 중 클릭 요청 파일만 설명 생성

가정 클릭률:

- 10%
- 30%
- 50%
- 100%

측정 방식:

- 각 정책을 10회 반복한다.
- 모델 로딩시간은 별도로 기록한다.
- 파일 읽기시간은 측정에서 제외한다.
- 정책 실행 순서는 반복마다 섞는다.

통과 기준:

- 의심 파일만 설명하는 정책의 설명 호출 수가 감소함
- 의심 파일만 설명하는 정책의 평균 처리시간이 20% 이상 감소함
- 클릭률이 낮을수록 설명 호출 횟수가 감소함
- 오류가 발생한 실행 0개

## 8. 제외한 실험

사용자 이해도 실험은 참여자를 확보하지 못하여 수행하지 않는다.

따라서 XAI가 사용자 이해도를 향상한다고 주장하지 않는다.

## 9. 데이터 제한

- 기존 모델 학습 데이터 전체 목록을 확보하지 못했다.
- 일부 파일은 학습 데이터와 중복될 수 있다.
- 탐지 모델의 일반화 성능을 증명하는 실험으로 해석하지 않는다.
- pilot 데이터는 코드와 실험 절차를 점검하는 데만 사용한다.
- 최종 결과에는 final manifest만 사용한다.
- 반복 실행 횟수를 독립적인 파일 표본 수로 계산하지 않는다.

## 10. 규약 변경

최종실험을 시작한 뒤 본 규약, 영향도 계산식, 피처 그룹,
정상 참조값 및 통과 기준을 변경하지 않는다.

변경이 불가피한 경우 변경 이유와 변경 전후 결과를 모두
기록하고 해당 실험을 별도 버전으로 구분한다.
